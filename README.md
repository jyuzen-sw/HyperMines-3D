# HyperMines 3D

立方体の外側からマスを開いていく、Astro・TypeScript・Three.js製の3次元マインスイーパーです。

## ゲームルール

盤面は `X × Y × Z` の立方格子です。開いたマスに表示される数字は、そのマスを囲む最大26マスに含まれる地雷数を表します。地雷以外のマスをすべて開くとクリア、地雷を開くと失敗です。

最初に選んだマスと、そのマスを囲む盤内の全近傍は必ず安全です。最初の数字は必ず0になり、安全なマスが連続して開きます。

### 外側から開く

開始時に操作できるのは立方体の外周だけです。

- 安全なマスを開くと閉じたマスが消え、奥のマスが操作可能になります。
- 旗を置くと閉じたマスが旗マーカーになり、同様に奥のマスを操作できるようになります。
- 旗を外すと閉じたマスが戻り、その旗だけで操作可能だった奥のマスも再び隠れます。
- 開いたマスの数字と周囲の旗数が一致すると、数字をクリックして周囲をまとめて開けます。

### 難易度

| 難易度 |      盤面 | 地雷 |
| ------ | --------: | ---: |
| 初級   | 5 × 5 × 5 |   10 |
| 標準   | 7 × 7 × 7 |   40 |
| 上級   | 9 × 9 × 9 |  100 |

## 操作

- 左クリック／「開く」モード: マスを開く
- 右クリック／「旗」モード: 旗を切り替える
- 数字をクリック: 周囲をまとめて開く
- 左ドラッグ／1本指: 盤面を回転する
- 右ドラッグ／2本指: 盤面を上下左右へパンする
- ホイール／ピンチ: 拡大縮小する
- 上部の 👆 / 🚩: 「開く」／「旗」モードを切り替える
- 上部の 🎯 / 🔗: 視点を戻す／共有URLをコピーする
- <kbd>1</kbd> / <kbd>2</kbd>: 「開く」／「旗」モード
- <kbd>R</kbd>: 同じseedと難易度で盤面を作り直す

## AIアシスト

AIアシストは、プレイヤーにも見える開いたマスの数字と旗だけを使用します。制約簡約、部分集合推論、連結成分ごとの全探索から安全または地雷と確定できた操作だけを実行し、確率による推測は行いません。

確定手がなくなると「運ゲーは人間の担当」として停止します。人間が一手操作した後、AIアシストボタンをもう一度押すと解析を再開します。

## 開発

Node.js 22.12以上が必要です。

```bash
npm ci
npm run dev
```

主な構成:

- Astro 7による静的ページ
- strict TypeScriptによるゲームドメインと観測情報だけを使うAI
- Three.jsのInstancedMesh・Raycaster・OrbitControlsによる3D盤面
- VitestによるゲームルールとAI判断の単体テスト
- Playwrightによるデスクトップ／モバイルのブラウザテスト

検証:

```bash
npm run verify
npm run test:e2e
```

Playwrightを初めて実行する場合はChromiumを導入してください。

```bash
npx playwright install chromium
```

## 共有URL

共有URLにはseed、難易度、最初に開いた座標が含まれます。最初の一手後にコピーしたURLは同じ一手から同一の地雷配置を再現しますが、途中の状態や経過時間は共有しません。

## GitHub Pages

`.github/workflows/deploy-pages.yml` はPull Requestで検証し、`main`へのpushまたは手動実行で静的サイトをデプロイします。独自ドメインや別の配下へ公開するときは、従来どおり `SITE_URL` と `BASE_PATH` を指定できます。
